# Generate Synthetic Data with Select AI for Python

## Introduction

This lab uses Oracle Select AI for Python to generate synthetic data in Autonomous AI Database. You will create movie, actor, and director tables, load the existing Select AI profile, generate and validate data for one or more tables, and optionally use the asynchronous API.

Estimated time: 30 minutes.

### Objectives

In this lab, you will:

- Connect to Autonomous AI Database using Select AI for Python.
- Create tables to hold generated data.
- Load an existing Select AI profile.
- Generate synthetic data for one table and multiple tables.
- Use natural-language prompts to guide generated data.
- Validate generated records with SQL queries.
- Optionally generate data with the asynchronous API.

### Prerequisites

Before starting, make sure that:

- Your Autonomous AI Database is provisioned and running.
- You created the `ADB_USER` database user.
- The database wallet is downloaded and extracted on the OCI Compute instance.
- Select AI for Python is installed in your Python virtual environment.
- An AI provider credential and Select AI profile have already been created.
- The `ADB_USER` schema has privileges to create and insert data into tables.
- Network access to the selected AI provider endpoint is configured.

## Task 1: Connect to Autonomous AI Database from Python

Create a reusable helper file named `select_ai_common.py`. If you created this helper in the previous lab, you can reuse it.

```python
<copy>
import os
import sys
from pathlib import Path

import select_ai


def required_env(name):
    value = os.getenv(name)
    if not value:
        print(f"Missing required environment variable: {name}")
        sys.exit(1)
    return value


def connect_to_adb():
    user = required_env("SELECT_AI_USER")
    password = required_env("SELECT_AI_PASSWORD")
    dsn = required_env("SELECT_AI_DB_CONNECT_STRING")
    wallet_dir = os.getenv("SELECT_AI_WALLET_DIR", "/home/opc/wallet")
    wallet_password = os.getenv("SELECT_AI_WALLET_PASSWORD")
    wallet_path = Path(wallet_dir)

    if not (wallet_path / "tnsnames.ora").exists():
        print(f"tnsnames.ora not found in {wallet_dir}")
        sys.exit(1)

    connect_args = {
        "user": user,
        "password": password,
        "dsn": dsn,
        "wallet_location": wallet_dir,
        "config_dir": wallet_dir,
    }
    if wallet_password:
        connect_args["wallet_password"] = wallet_password

    select_ai.connect(**connect_args)


def load_profile():
    profile_name = os.getenv("SELECT_AI_PROFILE_NAME", "oci_ai_profile")
    return select_ai.Profile(profile_name=profile_name)
</copy>
```

Create `lab4_task1_connect.py`:

## Task 4: Generate Synthetic Data for One Table

Generate 100 fictional movie records. The natural-language prompt asks for movies released in 2019, with varied genres, durations between 80 and 180 minutes, and ratings between 1.0 and 10.0.

Create `lab4_task4_generate_movies.py`:

```python
<copy>
import select_ai

from select_ai_common import connect_to_adb, load_profile


connect_to_adb()
profile = load_profile()

synthetic_data_params = select_ai.SyntheticDataParams(
    sample_rows=0,
    table_statistics=True,
    comments=True,
    priority="HIGH",
)
synthetic_data_attributes = select_ai.SyntheticDataAttributes(
    object_name="MOVIE",
    record_count=100,
    user_prompt=(
        "Generate fictional movie data. All release dates must be in 2019. "
        "Use a variety of genres, durations between 80 and 180 minutes, "
        "and ratings between 1.0 and 10.0."
    ),
    params=synthetic_data_params,
)

profile.generate_synthetic_data(
    synthetic_data_attributes=synthetic_data_attributes
)
print("Synthetic movie data generation completed.")
</copy>
```

Run the script:

```bash
<copy>
python3.12 lab4_task4_generate_movies.py
</copy>
```

Expected output:

```text
<copy>
Synthetic movie data generation completed.
</copy>
```

## Task 6: Generate Synthetic Data for Multiple Tables

This task generates data for `MOVIE`, `ACTOR`, and `DIRECTOR` in one request. First, remove the movie records generated in Task 4:

```sql
<copy>
TRUNCATE TABLE movie;
</copy>
```

Create `lab4_task6_generate_multiple_tables.py`:

```python
<copy>
import os
import select_ai

from select_ai_common import connect_to_adb, load_profile


connect_to_adb()
profile = load_profile()
user = os.getenv("SELECT_AI_USER")

synthetic_data_params = select_ai.SyntheticDataParams(
    sample_rows=0,
    table_statistics=True,
    comments=True,
    priority="HIGH",
)
object_list = [
    {
        "owner": user,
        "name": "MOVIE",
        "record_count": 100,
        "user_prompt": (
            "Generate fictional movie data. "
            "All movie release dates must be in 2019."
        ),
    },
    {
        "owner": user,
        "name": "ACTOR",
        "record_count": 25,
        "user_prompt": (
            "Generate fictional actors with varied nationalities and birth dates."
        ),
    },
    {
        "owner": user,
        "name": "DIRECTOR",
        "record_count": 10,
        "user_prompt": (
            "Generate fictional film directors with varied nationalities and birth dates."
        ),
    },
]
synthetic_data_attributes = select_ai.SyntheticDataAttributes(
    object_list=object_list,
    params=synthetic_data_params,
)

profile.generate_synthetic_data(
    synthetic_data_attributes=synthetic_data_attributes
)
print("Multi-table synthetic data generation completed.")
</copy>
```

## Task 8: Optional: Generate Synthetic Data Asynchronously

This optional task uses the asynchronous Select AI API. First, remove the movie records generated in Task 6:

```sql
<copy>
TRUNCATE TABLE movie;
</copy>
```

Create a separate helper file named `select_ai_common_async.py`:

```python
<copy>
import os
import sys
from pathlib import Path

import select_ai


def required_env(name):
    value = os.getenv(name)
    if not value:
        print(f"Missing required environment variable: {name}")
        sys.exit(1)
    return value


async def connect_to_adb():
    user = required_env("SELECT_AI_USER")
    password = required_env("SELECT_AI_PASSWORD")
    dsn = required_env("SELECT_AI_DB_CONNECT_STRING")
    wallet_dir = os.getenv("SELECT_AI_WALLET_DIR", "/home/opc/wallet")
    wallet_password = os.getenv("SELECT_AI_WALLET_PASSWORD")

    if not (Path(wallet_dir) / "tnsnames.ora").exists():
        print(f"tnsnames.ora not found in {wallet_dir}")
        sys.exit(1)

    connect_args = {
        "user": user,
        "password": password,
        "dsn": dsn,
        "wallet_location": wallet_dir,
        "config_dir": wallet_dir,
    }
    if wallet_password:
        connect_args["wallet_password"] = wallet_password

    await select_ai.async_connect(**connect_args)


async def load_profile():
    profile_name = os.getenv("SELECT_AI_PROFILE_NAME", "oci_ai_profile")
    return await select_ai.AsyncProfile(profile_name=profile_name)
</copy>
```

Create `lab4_task8_async_generate_movies.py`:

```python
<copy>
import asyncio

import select_ai

from select_ai_common_async import connect_to_adb, load_profile


async def main():
    await connect_to_adb()
    async_profile = await load_profile()

    params = select_ai.SyntheticDataParams(
        sample_rows=0,
        table_statistics=True,
        priority="HIGH",
    )
    attributes = select_ai.SyntheticDataAttributes(
        object_name="MOVIE",
        record_count=100,
        user_prompt=(
            "Generate fictional movie data. "
            "All movie release dates must be in 2019."
        ),
        params=params,
    )

    await async_profile.generate_synthetic_data(
        synthetic_data_attributes=attributes
    )
    print("Asynchronous synthetic movie data generation completed.")


asyncio.run(main())
</copy>
```

Run the script:

```bash
<copy>
python3.12 lab4_task8_async_generate_movies.py
</copy>
```

Expected output:

```text
<copy>
Asynchronous synthetic movie data generation completed.
</copy>
```

Verify the movie count:

```sql
<copy>

FROM movie;
</copy>
```

Expected result: `MOVIE_COUNT` is `100`.
